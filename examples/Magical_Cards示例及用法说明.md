
**插件的开发思路** 

我开发了一个自己用的工作台，最近改造到obsidian里后发现，这个卡片轮播的视觉效果出奇的好，大大提高了我的记录动力，不得不说 **颜值是第一生产力**

以前经常想要写读书笔记、观影笔记，最后总因为笔记长期维护难度大、反馈小而拖延放弃，而这个卡片轮播像集卡收藏一样，书籍影视就这么美丽地展现到我面前，我一回忆起曾经阅读或者观看的画面就忍不住点击进入笔记写上一两句作为记录。

进一步思考，我想到这个卡片轮播也可以单纯的只展示不记录，于是新增了橱窗功能，大家喜欢的照片、角色、明星等可以通过用橱窗功能，呈现在Magical Cards窗口以及你的任意笔记里。

这个插件是从我的Obsidian工作台里独立出来的，等我的工作台开发完善了我会带它和大家见面。**如果你有任何建议和反馈，欢迎给我提issue,或者作为contributor参与进一步开发我的插件，你也可以fork我的插件去自定义你的功能。**

## 打开和编辑卡片

使用左侧紫色叠卡图标，或命令「Magical Cards: 打开卡片视图」。阅读和影视是默认集合；也可以添加收藏模块。卡片视图与笔记内嵌入共用同一份作品笔记。

点击当前卡片可打开作品笔记，通过编辑入口修改名称、摘要、评分和封面。聚焦卡片后按 F，或点击当前卡片右上角的透明区域，可编辑背面的摘要；图片上没有翻面图标，其他区域仍打开笔记；返回正面时保存。保存冲突会保留草稿，不覆盖其他窗口的更新。也可直接编辑作品笔记的原生属性。

作品笔记默认只展开名称和摘要，其余信息在默认收起的“更多信息”中。观看日期和观看状态不再显示，已有数据保留。“导演”字段名称可逐张编辑，例如改成“开发商”，留空恢复默认。

在阅读、影视或普通模块菜单选择“批量导入图片／SVG”，一次选多张图片，每张建立独立卡片与笔记，名称取文件名、摘要留空。失败项保留重试，成功项不会重复添加；放弃重试保留已写入的笔记与图片。文件重试队列不跨应用退出保存。支持 PNG、JPEG、WebP、GIF 和安全 SVG，每图最多 10 MB，SVG 最多 2 MB。

模块比例可选择“32:15 宽幅横图”，适合约 2.13:1 的横幅；“2:3 竖向封面”适用于竖版图片。完整显示保留原图，填满裁切贴满卡片。

## 在笔记中嵌入

在设置中选择笔记代码块生成，选择你要加入笔记的卡片模块，复制代码块到你的笔记即可。

首次空库默认使用圆柱弧面、纸感、整幅封面、2:3、填满裁切（贴满卡片）和三张卡片的设置，可以根据个人偏好自行在高级设置中修改。**对卡片材质、样式、动效有新的需求或建议也可以点击上方传送门链接提issue，我后续更新去尝试开发和添加。**

## 调整顺序和外观

拖动模块标题前的手柄可以调整模块位置，聚焦手柄后按 Alt / Option + ↑、↓ 也可调整。每个 Dashboard 分别保存模块顺序；笔记内嵌入的模块顺序仅写入该代码块。卡片内的作品顺序可在作品排序笔记中调整。

可以在设置中选择圆柱弧面、封面流轮播、黑胶专辑架、滚动弯曲画廊或倾斜轮播。
弯曲画廊支持横向与竖向。

## 添加模块与图片橱窗

设置中的“添加卡片模块”和“添加图片橱窗”是两个独立入口，默认收起。按用途展开一个入口，填写名称、选择比例，可选已有 Dashboard 或新建分类并放入，再点击“保存并收起”即可；两个入口的类型固定、草稿独立。新模块默认整幅封面、填满裁切、纸感、2:3、倾斜轮播，关闭仅三张；此页的阅读和影视保留圆柱弧面和三卡预设。

其他选项都在默认收起的“高级设置”里，顺序为卡片样式、显示方式、材质、动效布局、仅显示三张卡片。三卡分别作用于各模块；同屏最多显示当前卡和两张邻卡，仍可浏览全部作品。

“添加图片橱窗”始终创建橱窗；高级卡片样式只选择整幅封面或简约，不转换模块类型。橱窗共用一个文件夹和一篇笔记；可以批量选择或拖入图片，不会自动扫描目录。每张图片的名称可留空，描述最多 400 字纯文本，背面自动保存。默认开启翻面、名称放在背面；高级设置可改为正面名称、不显示名称或关闭翻面。关闭翻面后仍可通过“编辑当前图片”修改资料。保存失败会保留草稿和已经创建的橱窗笔记，重试不会重复建笔记。

设置预览只供滑动浏览，不能翻面。点击左侧紫色卡片图标，在 Magical Cards 标签页体验翻面与编辑。展开模块后，标题右侧垃圾桶用于“删除模块”：确认后删除模块配置和所有分类引用，保留作品笔记、橱窗笔记及图片。原笔记嵌入会提示模块已删除，没有模块恢复入口。所属 Dashboard 旁的退出箭头只移出该分类，可在设置重新加入。

标签页里的模块操作收进横向菜单；删除当前卡片仅针对单张资料。删除橱窗单张卡片只移除笔记区块，保留原图片文件。成功提示四秒后消失，错误与待重试提示会保留。

## Dashboard 分类

Dashboard 用来分类卡片模块，每个分类同等，可以放入任意数量的模块。同一模块可主动加入多个分类，共用原有笔记和图片；标签页没有固定“全部”页。新用户首次安装的普通“示例” Dashboard 包含阅读和影视，可以改名、调整成员或删除；删除后不会自动恢复。

标签页横向分类菜单可新建、重命名或删除 Dashboard。拖动顶部标签，或聚焦后按 Alt / Option + ←、→，可以调整标签顺序；各分类内部模块顺序独立保存。

模块加入、移出和删除仅在插件设置里操作。展开模块后，可以选择已有分类，也可新建分类并放入。新模块没有选择分类时先留在设置，仍能嵌入笔记。所属分类右侧的退出箭头只移出该分类，其他分类和笔记嵌入继续显示；标题右侧的垃圾桶删除模块配置及所有分类引用，保留笔记和图片。

已有库升级不自动增加分类；旧隐藏模块移为未分类，取消旧隐藏状态，相关嵌入和兼容宿主恢复展示。共享运行时缺少功能时提示升级，原资料和草稿保留。

## 保存位置和再次查看

作品笔记保存在 `{{rootFolder}}/书籍` 和 `{{rootFolder}}/观影`，示例封面保存在 `{{rootFolder}}/附件`，卡片设置保存在 `{{rootFolder}}/_数据/卡片配置.md`。每个橱窗的共享笔记和导入图片在 `{{rootFolder}}/橱窗/<模块 ID>/`；打开 `橱窗.md` 即可看到全部图片。更换卡片目录不会搬动原目录中的作品。

命令「Magical Cards: 查看示例及用法说明」可再次打开此页。说明可自行编辑，升级和重启不会覆盖正文；删掉说明页或示例卡片后，启动不会再次自动导入示例。
