
**插件的开发思路** 

我开发了一个自己用的工作台，最近改造到obsidian里后发现，这个卡片轮播的视觉效果出奇的好，大大提高了我的记录动力，不得不说 **颜值是第一生产力**

以前经常想要写读书笔记、观影笔记，最后总因为笔记长期维护难度大、反馈小而拖延放弃，而这个卡片轮播像集卡收藏一样，书籍影视就这么美丽地展现到我面前，我一回忆起曾经阅读或者观看的画面就忍不住点击进入笔记写上一两句作为记录。

进一步思考，我想到这个卡片轮播也可以单纯的只展示不记录，于是新增了橱窗功能，大家喜欢的照片、角色、明星等可以通过用橱窗功能，呈现在Magical Cards窗口以及你的任意笔记里。

这个插件是从我的Obsidian工作台里独立出来的，等我的工作台开发完善了我会带它和大家见面。**如果你有任何建议和反馈，欢迎给我提issue,或者作为contributor参与进一步开发我的插件，你也可以fork我的插件去自定义你的功能。**

## 打开和编辑卡片

使用左侧紫色叠卡图标，或命令「Magical Cards: 打开卡片视图」。阅读和影视是默认集合；也可以添加收藏模块。卡片视图与笔记内嵌入共用同一份作品笔记。

点击当前卡片可打开作品笔记，通过编辑入口修改名称、摘要、评分和封面。聚焦卡片后按 F，或使用翻面入口，可编辑背面的摘要；返回正面时保存。保存冲突会保留草稿，不覆盖其他窗口的更新。也可直接编辑作品笔记的原生属性。

## 在笔记中嵌入

在设置中选择笔记代码块生成，选择你要加入笔记的卡片模块，复制代码块到你的笔记即可。

首次空库默认使用圆柱弧面、纸感、整幅封面、2:3、填满裁切（贴满卡片）和三张卡片的设置，可以根据个人偏好自行在高级设置中修改。**对卡片材质、样式、动效有新的需求或建议也可以点击上方传送门链接提issue，我后续更新去尝试开发和添加。**

## 调整顺序和外观

拖动模块标题前的手柄可以调整模块位置，聚焦手柄后按 Alt / Option + ↑、↓ 也可调整。“全部”和每个 Dashboard 分别保存模块顺序；笔记内嵌入的模块顺序仅写入该代码块。卡片内的作品顺序可在作品排序笔记中调整。

可以在设置中选择圆柱弧面、封面流轮播、黑胶专辑架、滚动弯曲画廊或倾斜轮播。
弯曲画廊支持横向与竖向。

## 添加模块与图片橱窗

设置中的“添加卡片模块”和“添加图片橱窗”是两个独立入口，默认收起。按用途展开一个入口，填写名称、选择比例，再点击“保存并收起”即可；两个入口的类型固定、草稿独立。新模块默认整幅封面、填满裁切、纸感、2:3、倾斜轮播，关闭仅三张；此页的阅读和影视保留圆柱弧面和三卡预设。

其他选项都在默认收起的“高级设置”里，顺序为卡片样式、显示方式、材质、动效布局、仅显示三张卡片。三卡分别作用于各模块；同屏最多显示当前卡和两张邻卡，仍可浏览全部作品。

“添加图片橱窗”始终创建橱窗；高级卡片样式只选择整幅封面或简约，不转换模块类型。橱窗共用一个文件夹和一篇笔记；可以批量选择或拖入图片，不会自动扫描目录。每张图片的名称可留空，描述最多 400 字纯文本，背面自动保存。默认开启翻面、名称放在背面；高级设置可改为正面名称、不显示名称或关闭翻面。关闭翻面后仍可通过“编辑当前图片”修改资料。保存失败会保留草稿和已经创建的橱窗笔记，重试不会重复建笔记。

设置预览只供滑动浏览，不能翻面。点击左侧紫色卡片图标，在 Magical Cards 标签页体验翻面与编辑。设置中展开模块后，标题右侧垃圾桶用于真正移除模块：确认后删除模块配置和所有分类引用，保留作品笔记、橱窗笔记及图片。原笔记嵌入会提示模块已移除，此操作没有模块恢复入口；暂时不显示请使用标签页中的“隐藏模块”，以后可恢复。卡片工具栏的垃圾桶删除当前单张卡片，不是移除整个模块。删除橱窗中的单张卡片只移除笔记区块，保留原图片文件。

## Dashboard 分类

Magical Cards 标签页顶部的“全部”展示所有未隐藏模块。点击右侧 `+` 新建 Dashboard，填写名称、勾选已有模块，再点击“保存 Dashboard”。新建时全部未勾选，新模块不会自动加入分类；只有主动勾选，同一模块才会加入多个 Dashboard，共用原有笔记和图片。

在分类中点击“编辑 Dashboard”可改名或调整成员；删除 Dashboard 仅删除分类。每个分类单独保存模块顺序，以稳定模块 ID 引用原资料，不改动作品笔记、图片或已有笔记嵌入的集合引用与局部顺序。

- 在“全部”中隐藏模块，会从 Magical Cards 标签页的“全部”和所有 Dashboard 隐藏；笔记嵌入继续显示。展开“全部”页面默认收起的“已隐藏模块”可恢复，沿用原分类、外观与顺序。
- 从 Dashboard 移出模块，只取消当前分类中的引用，“全部”和其他 Dashboard 不变。重新加入时，点击“编辑 Dashboard”，勾选原模块并保存。
- “移除模块”会删除模块配置和所有 Dashboard 引用，保留作品笔记、橱窗笔记与图片；原笔记嵌入提示模块已移除，没有模块恢复入口。
- 卡片工具栏的垃圾桶删除当前单张卡片，请与模块隐藏、移出分类区分。

隐藏可恢复，移出 Dashboard 只取消该分类的引用；真正移除模块会删除配置和分类引用，保留笔记与图片。若提示共享运行时缺少此功能，请升级已启用的兼容卡片插件并重启笔记库，原资料会保留。

## 保存位置和再次查看

作品笔记保存在 `示例/书籍` 和 `示例/观影`，示例封面保存在 `示例/附件`，卡片设置保存在 `示例/_数据/卡片配置.md`。每个橱窗的共享笔记和导入图片在 `示例/橱窗/<模块 ID>/`；打开 `橱窗.md` 即可看到全部图片。更换卡片目录不会搬动原目录中的作品。

命令「Magical Cards: 查看示例及用法说明」可再次打开此页。说明可自行编辑，升级和重启不会覆盖正文；删掉说明页或示例卡片后，启动不会再次自动导入示例。
