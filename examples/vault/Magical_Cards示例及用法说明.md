# Magical Cards 示例及用法说明

卡片目录是 `示例`。首次启用的全新空库会加入 3 本书和 3 部影视作品，以及保存在目录内的离线封面。示例是普通卡片，可编辑、移动或删除；删除后不会自动补回。已有库的作品、摘要和设置会保留。

## 打开和编辑卡片

使用左侧卡片图标，或命令「Magical Cards: 打开卡片视图」。阅读和影视是默认集合；也可以添加收藏模块。卡片视图与笔记内嵌入共用同一份作品笔记。

点击当前卡片可打开作品笔记，通过编辑入口修改名称、摘要、评分和封面。聚焦卡片后按 F，或使用翻面入口，可编辑背面的摘要；返回正面时保存。保存冲突会保留草稿，不覆盖其他窗口的更新。也可直接编辑作品笔记的原生属性。

## 在笔记中嵌入

运行命令「Magical Cards: 插入卡片模块」，选择一个或多个现有集合。新代码块使用 `magical-cards`；旧的 `barry-cards` 代码块继续可用。阅读模式和实时预览都可显示卡片。

以下代码引用阅读和影视两个集合，继承各集合的外观设置。首次空库默认使用圆柱弧面、纸感、整幅封面、2:3、填满裁切（贴满卡片）和三张卡片。

```magical-cards
id: demo-block-default
modules:
  - id: demo-module-default-books
    collection: book
  - id: demo-module-default-films
    collection: film
```

`collection: book` 对应阅读，`collection: film` 对应影视。收藏模块使用其集合标识，插入命令会生成正确代码。复制代码块时，请为代码块和模块生成新的 id；同一笔记的代码块 id 应唯一，单个代码块内的模块 id 也应唯一。

## 调整顺序和外观

拖动模块标题前的手柄可以调整模块位置，聚焦手柄后按 Alt / Option + ↑、↓ 也可调整。独立视图的模块顺序保存在卡片配置中；笔记内嵌入的模块顺序仅写入该代码块。卡片内的作品顺序可在作品排序笔记中调整。

可以在设置中选择圆柱弧面、封面流轮播、黑胶专辑架、滚动弯曲画廊或倾斜轮播。弯曲画廊支持横向与竖向；专辑架用于浏览封套，不提供播放按钮或抽出旋转唱片。设置中的图片比例、显示方式和外观预览可以帮助检查封面效果。

## 保存位置和再次查看

作品笔记保存在 `示例/书籍` 和 `示例/观影`，示例封面保存在 `示例/附件`，卡片设置保存在 `示例/_数据/卡片配置.md`。更换卡片目录不会搬动原目录中的作品。

命令「Magical Cards: 查看示例及用法说明」可再次打开此页。说明可自行编辑，升级和重启不会覆盖正文；删掉说明页或示例卡片后，启动不会再次自动导入示例。
