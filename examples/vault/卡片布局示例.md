# Barry Cards 布局示例

安装插件后，将卡片目录设为「示例」。8 张封面均使用本地资源，可断网查看。点击模块标题前的手柄可拖动排序，也可用 Alt + ↑ / ↓。

## coverflow-carousel

```barry-cards
id: demo-coverflow-carousel
modules:
  - id: demo-books-coverflow-carousel
    collection: book
    layout: coverflow-carousel
  - id: demo-films-coverflow-carousel
    collection: film
    layout: coverflow-carousel
```
